# 微博单篇原图下载

Chrome 扩展：在微博网页的某篇微博上右键，一次下载该篇微博可访问的全部原图。可设置 Chrome 下载目录下的子文件夹，并按博主名称和用户 ID 分类。详细行为见 [DESIGN.md](DESIGN.md)。

## 安装

1. 打开 Chrome 的 `chrome://extensions`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”，选择本项目目录。
4. 刷新已打开的微博页面。

## 使用

在微博内容或图片上右键，选择“下载这篇微博的全部原图”。点击浏览器工具栏里的插件图标可查看最近一次任务结果并进入设置页。

默认保存到 `Chrome 下载目录/微博原图/博主名_用户ID/`。Chrome 不允许扩展通过下载 API 指定任意绝对路径；若要更换主下载位置，请在 `chrome://settings/downloads` 中更改 Chrome 的下载目录。若开启了“下载前询问每个文件的保存位置”，Chrome 仍可能逐张弹出保存对话框。

本插件通过当前微博页面的登录状态读取帖子图片数据。图片站可能拒绝没有微博来源信息的直接下载；插件会在隐藏页面中读取并验证图片，再交给 Chrome 保存。无法取得明确原图地址或图片站返回错误网页时会报告失败，不下载缩略图。微博修改页面结构或接口后，解析代码可能需要更新。目前支持 `weibo.com` 和 `www.weibo.com` 的网页，不包含移动版和搜索站点。

更新本地代码后，请在 `chrome://extensions` 中点击本插件的“重新加载”，再刷新微博页面。
