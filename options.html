下载目录说明

文件保存在 Chrome 下载目录下，按平台、媒体类型、博主名称和帖子分类：

  • 微博 / 图片或视频 / 博主名称 / 帖子ID
  • Instagram / 图片或视频 / 用户名 / 帖子ID
  • X / 图片或视频 / 用户名 / 帖子ID

WebP 原文件、PNG 副本和 Live Photo 动态文件均放在对应的图片目录。

主下载目录由 Chrome 控制。如需更改磁盘位置，请前往 Chrome 的下载设置。

复制文件到 QQ／微信

先下载帖子，完成后打开插件弹窗，点击“复制全部原图”或“复制全部视频”，再到 Windows 版 QQ／微信群聊按 Ctrl+V，确认后发送。原图不重复复制 PNG 副本及 Live Photo 动态文件。

安装脚本会在当前用户的 LocalAppData 下编译并安装小助手，注册 Chrome 本机通信组件。更换扩展 ID 后需重新安装。群聊是否以图片、视频或文件形式展示由 QQ／微信决定；原文件不会转码或压缩。
